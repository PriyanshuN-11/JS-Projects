## Concepts Used

- **JavaScript fundamentals:** variables, data types, conditionals, loops, functions, arrow functions, destructuring, regular expressions
- **Data structures:** arrays, objects, 2D arrays, `Set`, and array methods (`map`, `filter`, `reduce`, `splice`)
- **Async JS:** timers, Fetch API, `async/await`, `try...catch`
- **DOM and events:** element creation, event handling, event delegation, form handling
- **Browser APIs:** `localStorage`, Canvas, Drag and Drop, File API, Clipboard
- **Data and APIs:** JSON, REST APIs, input validation, state management
- **Node.js:** `fs` module, terminal input with `prompt-sync`

## Purpose

This repository is a record of my JavaScript learning through practical
projects. Each one applies specific concepts such as DOM manipulation,
asynchronous programming, API integration and browser storage, with attention
to input validation, error handling and state management.
